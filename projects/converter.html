Le problèmeThe problem

Mon bureau de change en C# fonctionnait sur un seul ordinateur, avec des taux fixes. Je voulais une version accessible à tous dans le navigateur, avec les vrais taux du jour, et qui inclue la roupie mauricienne.

My C# currency exchange app ran on a single computer with fixed rates. I wanted a version anyone could use in the browser, with real daily rates, and including the Mauritian rupee.

Choix techniquesTechnical choices

  • JavaScript sans framework, pour maîtriser les bases : requêtes fetch, async/await et manipulation du DOM.
  • API publique de taux de change, avec un calcul croisé qui passe par le dollar américain comme base.
  • Déploiement sur Vercel et interface adaptée au téléphone.
  • JavaScript with no framework, to master the basics: fetch requests, async/await and DOM manipulation.
  • A public exchange-rate API, with cross-rate math using the US dollar as the base.
  • Deployed on Vercel with a mobile-friendly interface.

Défis et solutionsChallenges and solutions

Gérer les erreurs proprement quand l'API ne répond pas, et comprendre pourquoi une clé d'API ne doit jamais se trouver dans le code exécuté par le navigateur. Une fonction serveur (serverless) sur Vercel est la solution prévue si l'API exige une clé.

Handling errors cleanly when the API doesn't respond, and understanding why an API key must never live in code that runs in the browser. A serverless function on Vercel is the planned fix if the API requires a key.

RésultatsResults

Une application en ligne, utilisable sur ordinateur et téléphone, avec inversion des devises en un clic et conversion avec la touche Entrée.

A live app that works on desktop and mobile, with one-click currency swap and Enter-to-convert.

Ce que j'ai apprisWhat I learned

Refaire un projet existant dans une autre technologie est un excellent exercice : la logique était connue, je pouvais me concentrer sur le web, les API et le déploiement.

Rebuilding an existing project in another technology is a great exercise: the logic was known, so I could focus on the web, APIs and deployment.
